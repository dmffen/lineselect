## bidsummarize user script

Reads bid data and puts it in a more readable table

### Install

1. Install [Userscripts extension](https://itunes.apple.com/us/app/userscripts/id1463298887)
2. Enable extension; go to Settings > Apps > Safari > Extensions > Userscripts, set "Allow Extension" on
3. Open the script file in Safari: [bidsummarize.user.js](https://raw.githubusercontent.com/dmffen/lineselect/main/bidsummarize.user.js)
4. Tap "</>" extension icon in address bar, tap green banner to install script

### Use

1. Visit Bid Summary page
2. Extension adds "Summarize" button above bid report
